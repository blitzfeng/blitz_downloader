# 学习我的偏好

在设置页启用 AI 建议并配置 OpenAI、Gemini Developer API 或 Vertex AI，然后打开「学习我的偏好」。概览显示案例、逐标签判断来源、图证、待更新作品数和启用版本。历史反馈会标记为来源未知。手动增删标签、确认建议与纠正已有标签可以积累新的人工判断。

1. 点「预览全量学习计划」。核对发送的资料、服务与模型顺序、作品数、证据图数量和请求估算。确认开始后才发出学习请求。
2. 在任务页或通知查看进度。离开页面或按 Home 切到后台后，任务继续由前台服务执行。执行期间 App 会暂时保持 CPU 可运行，屏幕可以关闭。系统仍可能在深度休眠时限制网络，或结束服务。允许系统通知后可直接从通知查看进度。若服务中断，重新打开后点「继续未完成任务」，已成功保存的节点会直接复用。只有存在可能已经发送的请求时，才会要求确认是否允许再次提交。资料或模型发生不兼容变化时，重新预览学习计划。
3. 打开草稿，按标签展开正例、反例、来源未知的案例及可用图证。可保存人工覆写、恢复模型规则或关闭单条规则。启用标记为「待核实」的规则前，先核查并确认。
4. 点「应用此草稿」。历史版本兼容时可回滚。来源被删除、排除、修改，或依赖的标签定义变更后，相关版本会失效。
5. 分析新视频并打开「AI 分析日志」。日志显示规则版本、选中和省略的规则、当前和历史图片数、文本案例数。复制日志可以同时取得准备分段和每次 HTTP 尝试的上传、等待、接收与报文大小。

## 任务检查点

学习策略版本为 1。提炼节点最多包含 8 个作品和 4 张低分辨率图片。序列化文字最多 32 KiB，图证最长边 384 px，每张最多 512 KiB，单批文字及 Base64 总量最多 3 MiB。每个合并节点最多包含 8 个同作用域子节点。规则正文最多 512 个 Unicode 字符。单节点请求含降级总计最多 120 秒。

| 状态 | 含义 |
| --- | --- |
| 等待开始 | 学习范围已经冻结，等待确认 |
| 正在提炼或合并 | 节点按序执行，成功结果与覆盖关系写入 Room |
| 等待审核规则 | 所需节点成功，草稿可以查看 |
| 失败 | 失败节点可重试 |
| 已取消或中断 | 保留成功检查点，运行中的请求可能再次计费 |
| 计划过期 | 引用资料或配置已变化，需重新预览 |

准备时间使用单调时钟，按请求独立记录。首次 HTTP 调用开始时结束准备计时，后续服务尝试保留各自的网络统计。采样时使用相同设备、模型、当前视频图片和候选词表。
