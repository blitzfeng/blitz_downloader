- [x] 1.3 实现 session/work/candidate/batch 状态与 revision 条件更新、主键去重和进程中断状态恢复；测试覆盖重复命令、过期审核、提交前后重启及不自动联网/写回。
- [x] 1.4 增加 recovered 来源及 provenance 的历史未知模型；纯规则测试确认原下载时间未知与恢复时间、兼容零值与原历史零值可以区分。

- [x] 2.3 实现文件名 ID、证据帧 ID、图集序号和人工作品链接解析；JVM 测试覆盖同 ID 多文件、 `(1)` 后缀、哈希后缀、非法 ID、断号图集、短链接白名单及不编造 ID。

## 3. 作品详情查询协议

- [x] 3.1 按 design 第 6 节的实施说明，在相同详情地址和既有登录态上增加类型化 HTTP 结果，并保持旧 Parser 调用兼容及协程取消传播；使用 MockWebServer/OkHttp 模拟响应测试 HTTP 分类、空正文、解析异常、ID 不符和合法详情映射，不访问真实账号。
- [x] 3.2 实现并发 2、发起间隔、超时、限次退避和 429 停队策略；可注入时钟测试证明首次请求与重试都受速率限制，暂停后不继续出队。
- [x] 3.3 实现逐 ID 检查点、24 小时缓存、authScopeHash 和显式续跑；测试覆盖进程中断、重复 ID、登录变化、缓存失效、已完成结果不丢失与旧确认失效。
- [x] 3.4 归一化存储详情并限制响应/DTO 大小，记录无敏感内容的错误与计时；测试超限数据不能截断后认定成功，数据库、日志和报告不含 Cookie/Key/签名 URL。
- [x] 3.5 更新接口契约说明，区分 awemeId、sec_user_id、昵称和 F2 query_user，记录真实查询的小样本前置条件；核对本版没有隐藏的作者全量抓取或昵称搜索。

## 4. 本地匹配与审核指纹

- [x] 4.1 实现直接文件名 ID 的候选召回、类型/时长核验和多副本冲突；测试同 ID 两文件、类型不符、时长异常及已存在 ID 不被自动覆盖。
- [x] 4.2 实现旋转归一化 dHash-64 封面索引及证据帧召回，按设计阈值、第二候选差距和规则版本返回依据；正反样例验证同作者同描述不同画面不会变为已确认关联。
- [x] 4.3 实现每作品最多 5 个视频、每视频最多 12 帧、并发 1 和有界缓存的中段帧核验；测试取消释放解码资源、不同帧约束、没有合理召回时不全盘穷举抽帧。
- [x] 4.4 实现图集分组审核、人工选择/排除/补充链接、单项及 READY 集合显式确认；测试排序、重复序号、实况媒体、未选主文件保留，以及评分不能自动进入 CONFIRMED。
- [x] 4.5 实现 detailHash、文件全文哈希、policyVersion 与 candidateRevision 的确认指纹，补充匹配规则说明及合成校准集；测试任意相关输入变化后旧选择不可写回，不输出未经实测的成功率。
