## Context

应用现有 Gemini 和 Vertex AI 配置通过同一个提供方接口调用，历史反馈由本地数据库维护。

## Decisions

- 每个服务保存自己的凭据和模型。旧设置中选择的服务作为初始首选。清空某项 Key 后，分析会跳过该项。
- 分析按顺序调用服务，网络异常、HTTP 408、429、5xx 时尝试下一项。内容拦截及其他错误直接报告。分析记录保存实际成功的提供方。
- OpenAI 复用标签词表、图片、历史案例和响应数据模型，使用 Responses 的严格 JSON Schema。连接测试只调用设置显示的首选服务。
- 自用 App 使用用户在本机输入的 OpenAI Key 直连固定端点，密钥不随 APK 分发。
