# 相机目录整理

在设置页打开「整理相机目录」，点击「扫描 / 授权」，核对预览后点击「确认移动」。打开设置页、授权返回或取消预览都不会自动移动文件。

## 扫描范围与规则

仅扫描主共享存储 `DCIM` 本层及 `DCIM/Camera` 本层的文件，不扫描 DCIM 下其他子目录或 Camera 内的子目录。Camera 不存在时仍处理 DCIM 本层；目录读取失败会显示错误，不作为空目录处理。

| 类型 | 保留的文件名前缀（忽略大小写） | 其他文件的目标目录 |
|---|---|---|
| 视频 | `img`、`vid` | `Download/history` |
| 图片 | `img`、`mvimg`、`pano`、`retouch` | `Download/history_img` |

未知类型不处理。文件名规则不能鉴定真实拍摄来源；例如 `VID_001.jpg` 属于图片移动候选。预览逐项显示文件名、大小、来源和目标，同名的两个来源文件分别处理，目标重名时追加序号，不覆盖已有文件。

## 权限

- Android 11 及以上：授予所有文件访问权限。
- Android 10：依次选择主共享存储的 `DCIM` 和 `Download` 目录。旧版仅有 Camera 授权时需重新选择 DCIM；授权 DCIM 不意味着扫描其所有子目录。
- Android 6–9：授予读写外部存储权限。

## 失败与恢复

复制并校验目标成功后才删除源文件。源文件变化、复制失败或权限不足会跳过、报错或停止批次；删除源失败时保留完整目标副本，并显示其位置。结果可区分两个来源的同名文件，媒体索引同步按实际源路径执行。

进程重启不自动继续移动或删除文件。未完成文件记录仅用于提示，由用户通过文件管理器核对。需要撤销时，根据原来源目录手工将文件移回 DCIM 或 DCIM/Camera。本功能不导入应用下载记录，也不改动 `.nomedia` 隐藏设置。
